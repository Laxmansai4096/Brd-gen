,4. THE ELEVEN DELIVERY TIERS  —  definitions,,
,PoC,"Proof of Concept. Throwaway build that answers one question: is this technically feasible? Happy path only, synthetic or sampled data, no NFRs, no security review, no CI/CD, single environment, demo-only UI. Not deployed to real users.",
,Pilot,"Limited live trial with a controlled user cohort on real data. Basic auth, basic logging, manual operations, light NFRs, time-boxed. Refactor expected before scale-up. Usually runs in a non-production or ring-fenced environment.",
,MVP,"Minimum Viable Product. Smallest releasable product slice with a real user base. Production-grade hardening on the critical path, automated deployment, core security and Responsible AI controls, documented runbooks, but deliberately reduced scope, limited HA/DR, and accepted technical debt logged.",
,Production Grade,"Full production readiness. Complete functional scope, enforced NFRs (performance, availability, HA/DR), full security and Responsible AI gates, infrastructure as code, CI/CD, observability, cost governance, load and UAT testing, formal cutover, hypercare and operational handover.",
,PoC to Pilot,"Uplift of an existing PoC to a controlled live trial. Charges only the delta between PoC and Pilot rigour, plus a rework uplift because PoC artefacts are rarely reusable as-is, plus a mobilisation floor for re-discovery and re-baselining.",
,PoC to MVP,Uplift of an existing PoC directly to a releasable MVP. Charges the PoC-to-MVP rigour delta plus rework uplift and mobilisation floor. Expect substantial re-architecture as PoC shortcuts are unwound.,
,PoC to Production Grade,Uplift of an existing PoC straight to full production readiness. Charges the full rigour delta plus rework uplift and mobilisation floor. Highest-risk transition: most PoC code is replaced rather than extended.,
,Pilot to MVP,Uplift of a running pilot into a releasable MVP. Charges the Pilot-to-MVP rigour delta plus rework uplift and mobilisation floor. Pilot learnings usually reduce requirement churn.,
,Pilot to Production Grade,"Uplift of a running pilot to full production readiness. Charges the Pilot-to-Production rigour delta plus rework uplift and mobilisation floor. Dominated by NFR, security, HA/DR and operational readiness work.",
,MVP to Production Grade,"Hardening of a live MVP to full production grade. Charges the MVP-to-Production rigour delta plus rework uplift and mobilisation floor. Dominated by scale, resilience, full Responsible AI certification and technical-debt paydown.",
,Incremental Production Grade,"A delta release onto an existing, already-live production solution. Effort covers only the incremental change plus mandatory regression, impact assessment, re-certification of affected controls and release management. Platform, CI/CD and observability already exist and are reused.",
,How the multiplier works,"The engine is the phase-applicability table on '03 Multipliers': for each of the 18 delivery phases it holds how much of that phase is actually performed at PoC, Pilot, MVP and Production rigour. A base tier reads its column directly. A transition tier charges (target phase weight minus source phase weight) x rework uplift, plus a mobilisation floor, phase by phase — so 'MVP to Production Grade' charges the hardening delta only, not the whole build. Incremental Production Grade charges a configurable share of the full Production column. The single headline weight shown against each tier is a derived, effort-weighted summary of those phase factors: it is a read-out, not the driver. Every weight, the rework uplift, the mobilisation floor and the incremental share are editable.",

,5. RESPONSE CONTRACT AND THE TOLERANT PARSER,,
,Block format,"Copilot is instructed to return each dataset inside <<<BEGIN:NAME>>> ... <<<END:NAME>>> markers. Inside a block, one record per line, fields separated by the pipe character, and the first line is a header line starting with the word HEADER.",
,Line-end delimited,"Record termination is the line break, not a delimiter character. That is what keeps the parser simple: split on the line break, then split each record on the pipe.",
,Fewer columns than expected,"Handled. Missing expected columns are filled with the not-provided token from '01 Config', and every instance is written to '92 Parse Log'.",
,Different column names,"Handled. Headers are normalised (case, spacing and punctuation stripped), matched against a synonym table, then scored on token overlap. Anything below the Config threshold is treated as unmapped. Where the response returns exactly the right number of columns under different names, a positional fallback is applied and flagged loudly.",
,Extra or unmapped columns,"Quarantined to '93 Unmapped' with the block name, record number and raw header. Never silently dropped, never merged into a mapped column.",
,Oversize values,"Any field longer than the Config limit is written truncated with a marker, and the full value is appended to '93 Unmapped'. Excel's own hard limit is 32,767 characters per cell.",
,Markdown tolerance,"Leading and trailing table pipes, dash separator rows, code fences and bold markers are stripped rather than parsed as data.",
,Nothing is invented,"The parser never fabricates a value. If Copilot omits something you will see the not-provided token, not a plausible guess.",

COPILOT SESSION,,,
LLM / model to select in Copilot,GPT-5 Thinking / Reasoning,,Written into the COPILOT SESSION SETUP header of every exported prompt. Select this model in the Copilot model picker before pasting.
Grounding mode,Work,,Work = tenant data only. Web = public internet. Work and Web = both. Written into the prompt header; you set the matching toggle in Copilot.
Copilot surface,M365 Copilot Chat,,M365 Copilot Chat is the supported surface for prompts of this size. Copilot in Excel cannot ingest them.
Copilot licence attested,Yes,,"Set by Step 0. VBA cannot read your licence, so this is an attestation. Copilot steps stay locked while this is No."
Prompt / response folder,,,Leave blank to use the workbook's own folder. Both file dialogs open here by default.
,,,
ESTIMATION UNIT AND CONVERSION,,,
Estimation unit,Person-Days,,Drives the derived effort column on '20 Estimates'.
Hours per person-day,9.0,,Used when the unit is Person-Hours.
Working days per week,5,,Mon-Fri by default. Change only if you genuinely run a different week.
Person-days per story point,1.0,,Used when the unit is Story Points. One point equals one person-day by default.
Productive utilisation %,100.0%,,"Share of a working day spent on estimated tasks. The rest is meetings, email and context switching. Default was 80%"
Leave and buffer %,0.0%,,"Blanket allowance for annual leave, sickness and unplanned absence across the engagement.Default was 8%"
Contingency %,10.0%,,"Applied to the summed task effort. Shown as a separate line, never buried inside task rows."
PM and governance overhead %,12.0%,,Applied on top of delivery effort. Phase P18 tasks are excluded from the base to avoid double counting.
,,,
SCHEDULE AND FEASIBILITY,,,
Max FTE per role (peak),20.0,,Above this a feasibility flag is raised and the schedule is stretched. 2.0 means at most two people concurrently in one role. Note it is applied on week so 1 means effort is 1. Keep what max can be loaded
Max ramp per week (people),80.0,,Maximum net headcount increase between consecutive weeks across the whole team.
Phase overlap fraction,0.50,,How much of a phase may run concurrently with the next. 0 = strict waterfall. 0.35 means the next phase starts when the current one is 65% elapsed.
Min FTE granularity,0.25,,Headcount is rounded up to this granularity when checking the ramp constraint.
Day-level detail cut-off (weeks),999,,"999 = full day-level for the entire engagement, as configured. Lower it only if the row count becomes unwieldy."
Max rows on Day-wise Tasks,30000,,Hard stop that protects workbook performance. The macro warns and truncates rather than hanging.
,,,
PROMPT AND PARSER,,,
Max prompt characters,"500,000",,Ceiling for an assembled prompt. Above this the builder warns and suggests attaching the file rather than pasting.
Max response characters,"1,000,000",,Ceiling for an imported response. Above this it is still read in full and a warning is logged.
Sheet mirror chunk size,"30,000",,"Characters per cell when mirroring onto '90 PROMPT OUT' and '91 RESPONSE IN'. Excel's own limit is 32,767."
Field delimiter,|,,Pipe. Copilot is instructed to replace any literal pipe inside a value with a forward slash.
Not-provided token,NOT PROVIDED,,Written into any expected column the response omitted. Deliberately conspicuous.
Header match threshold,0.72,,"Token-overlap score below which a response column is treated as unmapped. 0 accepts anything, 1 demands an exact match."
Max field characters,"32,000",,Longer values are truncated in-cell with a marker and the full text goes to '93 Unmapped'.
